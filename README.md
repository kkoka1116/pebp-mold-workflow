# PEBP mold workflow

Static page showing how to cast a pre-epiglottic baton plate in cold-cure PMMA using 3D-printed tooling, with an interactive demold sequence.

Live page: https://kkoka1116.github.io/pebp-mold-workflow/

**Research and demonstration only. Not a medical device.** Nothing here has been printed, cast or clinically reviewed.

The 3D model in `kit.json` is a synthetic palate built from published means. The repository contains no patient data.
